# Modelos de portfólio

Três modelos de página única, prontos para adaptar a clientes. Abra cada `index.html` com o Live Server.

| Pasta | Para quem | Destaque |
|---|---|---|
| `doces/` | MEIs de doces e confeitaria | Cardápio com preços e passo a passo da encomenda |
| `personal/` | Personal trainers | Tabela de preço por aula, treinos e wellness |
| `social/` | Influenciadores e social medias | Feed de conteúdo, números e serviços |

## Como adaptar (leva uns 15 minutos)

1. **WhatsApp:** busque `5500000000000` (Ctrl+Shift+F) e troque pelo número do cliente (55 + DDD + número).
2. **Nome e textos:** busque `[` para achar os trechos entre colchetes e `Nome`, `00` para os números.
3. **Cores:** variáveis em `:root` no topo do `<style>`.
4. **Fotos:** coloque os arquivos em `img/` e, no elemento com classe `img`, adicione `style="--src:url(img/foto.jpg)"`. Se já houver um `style`, acrescente `;--src:url(...)` dentro dele.
5. **Instagram:** busque `seuperfil` e troque pelo @ do cliente.

Todos os valores, números e depoimentos são exemplos. Substitua por dados reais antes de publicar.
